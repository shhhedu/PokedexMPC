================================================================================
             DOCUMENTAÇÃO COMPLETA — POKÉDEX (Projeto Web)
      Explicação detalhada de cada arquivo, função e trecho de código
================================================================================

Este documento explica de forma detalhada todo o código do projeto Pokédex,
dividido em três arquivos: index.html, style.css e script.js.

O projeto consiste numa Pokédex interativa dos 151 Pokémon originais (Geração I),
com tela de carregamento animada, tela de título com menu, tela de créditos
e a Pokédex em si com busca, favoritos, evoluções e fundos dinâmicos por tipo.

================================================================================
  PARTE 1 — index.html (Estrutura HTML)
================================================================================

LINHA POR LINHA:

<!DOCTYPE html>
  → Declara que o documento é HTML5.

<html lang="pt-BR">
  → Elemento raiz do HTML. O atributo lang="pt-BR" indica que o conteúdo
    está em português brasileiro, ajudando leitores de tela e motores de busca.

<head>
  → Seção de metadados do documento (não visível ao usuário).

<meta charset="UTF-8">
  → Define a codificação de caracteres como UTF-8 (suporta acentos, emojis, etc.).

<meta name="viewport" content="width=device-width, initial-scale=1.0">
  → Configura o viewport para responsividade em dispositivos móveis.
    width=device-width: a largura da página será a largura do dispositivo.
    initial-scale=1.0: o zoom inicial será 100%.

<title>Pokédex</title>
  → Define o título que aparece na aba do navegador.

<link rel="stylesheet" href="style.css">
  → Importa o arquivo CSS externo com todos os estilos visuais.

<link href="https://fonts.googleapis.com/css2?family=Press+Start+2P&display=swap"
      rel="stylesheet">
  → Importa a fonte "Press Start 2P" do Google Fonts.
    Essa é uma fonte pixelada, estilo retro/8-bit, usada em todo o projeto.

</head>
<body>
  → Início do corpo visível da página.

================================================================================
  PARTE 2 — style.css (Estilos CSS)
================================================================================

O CSS está organizado em seções que correspondem a cada tela do projeto.
Abaixo, cada seção é explicada em detalhes.

---- RESET GLOBAL ----

* { margin: 0; padding: 0; box-sizing: border-box; }
  → Reset universal: remove margens e paddings padrão de todos os elementos.
    box-sizing: border-box faz com que padding e border sejam incluídos
    no tamanho total do elemento (facilita o layout).

body { background: #000; overflow: hidden; width: 100vw; height: 100vh;
       font-family: 'Press Start 2P', monospace; }
  → Corpo ocupa toda a viewport, fundo preto, sem scroll.
    Fonte pixelada "Press Start 2P" com fallback para monospace.

.hidden { display: none !important; }
  → Classe utilitária para esconder elementos. O !important garante
    que sobrepõe qualquer display definido.

---- TELA DE CARREGAMENTO ----

#loading-screen
  → position: fixed + inset: 0 → cobre toda a tela.
    z-index: 1000 → fica acima de tudo.
    transition: opacity 1s ease → fade-out suave quando a classe é adicionada.

#loading-screen.fade-out
  → opacity: 0 + pointer-events: none → torna invisível e não clicável.

Animação breathe: sobe e desce suavemente (translateY + scale), simulando
  a respiração do Snorlax dormindo. Ciclo de 2.2s.

Animação zPulse: o texto "Z z z" pulsa entre opacidade 0.3 e 1.
  Ciclo de 1.4s.

Animação popExcl: quando o Snorlax "acorda", o "!" aparece com efeito
  de escala (de 0.3 para 1.5 e volta para 1). Duração: 0.4s.

Animação wakeUp: o container do Snorlax sobe, cresce e desaparece.
  Simula o Snorlax saindo da tela.

---- TELA DE TÍTULO ----

#title-screen
  → Cobre toda a tela. z-index: 500.

.black-bar, .top-bar
  → Barra preta decorativa no topo (5% da altura).

#forest-bg
  → Posicionado absolutamente, ocupa 85% central da tela.
    Começa invisível (opacity: 0), revelado com animação fadeIn.

#forest-img
  → object-fit: cover → a imagem preenche todo o container sem distorção.
    image-rendering: pixelated → mantém o estilo pixel art sem suavização.

Animação logoDrop:
  → A logo cai de translateY(-700px) até a posição final.
    Tem um efeito de bounce com 4 keyframes:
    0%: acima da tela, invisível
    55%: passa da posição final (12px abaixo)
    72%: volta um pouco para cima (-10px)
    88%: desce levemente (4px)
    100%: posição final
    cubic-bezier(.22,1,.36,1) → curva de aceleração suave.

.menu-item.selected::before
  → Pseudo-elemento que mostra o cursor "▶" à esquerda do item selecionado.
    Pisca com animação cursorBlink (step-end = sem transição suave).

#bottom-bar
  → Barra no rodapé com gradiente vermelho, borda superior escura.

---- TELA DE CRÉDITOS ----

#credits-bg
  → Fundo com imagem "integrantes.jpg", blur de 4px e escurecimento.
    O fallback de cor é #0e0e1a (azul muito escuro).

.member-card
  → Cartões com fundo semi-transparente e backdrop-filter: blur(12px)
    (efeito vidro fosco). Animação memberSlide com delay escalonado
    (0.1s, 0.2s, 0.3s, 0.4s) para entrada sequencial.

---- POKÉDEX — FUNDO DINÂMICO ----

#type-bg-image

    saturate(1.3) → aumenta levemente a saturação das cores.
    transition: background-image 1.2s ease → troca suave entre imagens.

#type-bg-overlay
  → Camada colorida sobre a imagem. A cor é definida via JS

---- POKÉDEX — HEADER ----

#pokedex-header
  → Barra vermelha similar ao bottom-bar da tela de título.

---- POKÉDEX — PAINEL ESQUERDO ----

------------------------------------------------------------------------
FUNÇÕES DA TELA DE CARREGAMENTO (INTRO)
------------------------------------------------------------------------

function simulateLoading()
  → Retorna uma Promise que simula um carregamento.
    Dois setInterval rodam simultaneamente:
    1) zI (a cada 400ms): alterna o texto "Z", "Z z", "Z z z"... ciclicamente.
    2) lI (a cada 80ms): incrementa uma variável de progresso (p) com valor
       aleatório (Math.random()*3+1). Quando p >= 100, ambos os intervalos
       são limpos e a Promise resolve.
    O tempo total é aleatório (cerca de 2-4 segundos).

function snorlaxWakeUp()
  → Retorna uma Promise que anima o "despertar" do Snorlax.
    Sequência:
    t=0ms: texto muda para "!" e classe 'awake' é adicionada (efeito pop)
    t=800ms: classe 'waking-up' → Snorlax sobe e some (animação CSS)
    t=1400ms: tela de loading faz fade-out (classe 'fade-out')
    t=2400ms: loading-screen é removido do display → Promise resolve

function showTitleScreen()
  → Remove 'hidden' do title-screen, muda currentScreen para 'title'.
    Após 100ms, inicia a revelação do fundo da floresta (fade-in).
    Resolve após 1400ms.

function dropLogo()
  → Adiciona classe 'drop-in' no container da logo, ativando a animação
    CSS logoDrop (queda com bounce). Resolve após 1200ms.

function showMenu()
  → Mostra o menu de opções (remove 'hidden', adiciona 'show').
    Reseta menuIndex para 0 e atualiza a seleção visual.

function updateMenuSelection()
  → Percorre todos os .menu-item e adiciona/remove a classe 'selected'
    baseado no menuIndex atual.

SELECIONAR POKÉMON — A FUNÇÃO PRINCIPAL
------------------------------------------------------------------------

async function selectPokemon(id)
  → Função central que atualiza toda a interface quando um Pokémon é
    selecionado. Passos:

    1) Atualiza currentPokemonId e destaca na lista (highlightSelected)
    2) Adiciona ao Set de vistos (seenSet.add) e atualiza contadores
    3) Busca dados completos da API (fetchPokemon)
    4) Atualiza nome e número no painel esquerdo
    5) Carrega sprite:
       - Tenta GIF animado da Gen V (Black/White)
       - Se falhar, usa artwork oficial ou sprite padrão
       - Faz fade (opacity 0 → 1) durante a troca
    6) Gera badges de tipo no container #pokemon-types
    7) Atualiza fundo dinâmico (updateTypeBackground) com o tipo primário
    8) Preenche as barras de stats:
       - Mapeia nomes da API para IDs dos elementos (hp→hp, attack→atk...)
       - Calcula percentual: (base_stat / 255) * 100, máximo 100%
       - Define largura da barra e cor (verde/laranja/vermelho)
       - Mostra valor numérico
    9) Preenche peso (hectogramas→kg), altura (decímetros→m), habilidade
    10) Atualiza botão de favorito
    11) Carrega cadeia de evolução (loadEvolutions)

function updateTypeBackground(type)
  → Recebe o nome do tipo (ex: 'fire') e:
    1) Busca a URL da imagem em TYPE_BACKGROUNDS (ou usa 'normal' como fallback)
    2) Define como background-image do #type-bg-image
    3) Define a cor do overlay usando OVERLAY_COLORS
    A troca é suave graças às transições CSS.

FUNÇÕES DE FETCH (REQUISIÇÕES À API)
------------------------------------------------------------------------

async function fetchPokemon(id)
  → Busca dados completos de um Pokémon na PokeAPI.
    URL: https://pokeapi.co/api/v2/pokemon/{id}
    Retorna objeto com: name, types, stats, sprites, weight, height,
    abilities, etc.
    Usa cache (pokemonCache) para evitar requisições duplicadas.

async function fetchSpecies(id)
  → Busca dados da espécie do Pokémon.
    URL: https://pokeapi.co/api/v2/pokemon-species/{id}
    Retorna objeto com: evolution_chain (URL da cadeia evolutiva), etc.
    Usa cache (speciesCache).

------------------------------------------------------------------------
FUNÇÕES DE EVOLUÇÃO
------------------------------------------------------------------------

async function loadEvolutions(id)
  → Carrega e exibe a cadeia evolutiva do Pokémon.
    Passos:
    1) Mostra "Carregando..." no container de evoluções
    2) Busca dados da espécie (fetchSpecies)
    3) Se não houver cadeia evolutiva, mostra "—"
    4) Busca dados da evolução (ou usa cache)
    5) Percorre a cadeia encadeada:
       A PokeAPI estrutura evoluções como uma árvore (linked list):
       chain → { species, evolves_to: [{ species, evolves_to: [...] }] }
       O while percorre o primeiro caminho (evolves_to[0]).
    6) Gera elementos HTML:
       - Para cada estágio: div.evo-item com sprite (PNG) e nome
       - Entre estágios: span.evo-arrow com "→"
       - O estágio atual recebe classe 'current' (destaque)
       - Cada item é clicável → selectPokemon(evo.id)

function extractId(url)
  → Extrai o ID numérico de uma URL da PokeAPI.
    Ex: "https://pokeapi.co/api/v2/pokemon-species/25/" → 25
    Remove a barra final, split por '/' e pega o último elemento.

FLUXO DO USUÁRIO:
  1. Página carrega → Snorlax dorme com "Z z z"
  2. "Carregamento" completa → Snorlax acorda (!) e some
  3. Tela de título aparece: floresta + logo + menu
  4. Usuário navega com ↑↓ e ENTER (ou mouse)
     → START: abre a Pokédex
     → CREDITS: mostra os créditos
  5. Na Pokédex:
     - Lista de 151 Pokémon à direita (25% da tela)
     - Detalhes do Pokémon selecionado à esquerda (75%)
     - Busca por nome ou número
     - Aba de favoritos (salvos no localStorage)
     - Fundo muda conforme o tipo do Pokémon
     - Cadeia evolutiva clicável
     - Botão ◀ MENU para voltar

APIs UTILIZADAS:
  - PokeAPI (https://pokeapi.co/api/v2/) — dados de Pokémon
  - PokeAPI Sprites (GitHub) — imagens dos Pokémon
  - Google Fonts — fonte "Press Start 2P"

TECNOLOGIAS:
  - HTML5 semântico
  - CSS3 (Flexbox, animações, transições, backdrop-filter, gradientes)
  - JavaScript ES6+ (async/await, Promises, fetch API, Set, localStorage)
  - Nenhum framework ou biblioteca externa

ARMAZENAMENTO LOCAL:
  - localStorage chave 'pokedex-favorites' → array JSON de IDs favoritos
  - Cache em memória (pokemonCache, speciesCache, evoCache) → evita
    requisições repetidas durante a mesma sessão
