# PokedexMPC

PokedexMPC é uma aplicação web desenvolvida em JavaScript, CSS e HTML, que traz uma experiência interativa e nostálgica de uma Pokédex digital inspirada nos jogos de Pokémon. O projeto foi feito para apresentar informações sobre todos os 151 Pokémon da primeira geração de forma visual e intuitiva.

## Funcionalidades

- **Listagem dos 151 Pokémon originais**: Acesse rapidamente todos os Pokémon da primeira geração através de uma interface amigável.
- **Filtros e buscas**: Permite filtrar Pokémon por nome, tipo e outras características.
- **Detalhes dos Pokémon**: Veja informações como nome, número, tipos, sprites e estatísticas base (HP, Ataque, Defesa etc).
- **Favoritos**: Marque e visualize seus Pokémon favoritos usando armazenamento local (localStorage).
- **Navegação por teclado**: Use o teclado para navegar pela lista de Pokémon.
- **Visual dinâmico**: O fundo da Pokédex muda conforme o tipo do Pokémon selecionado, tornando a navegação mais imersiva.

## Tecnologias Utilizadas

- **JavaScript**
- **CSS**
- **HTML**

## Como usar

1. Clone este repositório em sua máquina:
   ```bash
   git clone https://github.com/shhhedu/PokedexMPC.git
   ```
2. Abra o arquivo `index.html` em um navegador de sua preferência.
3. Aproveite a Pokédex!
